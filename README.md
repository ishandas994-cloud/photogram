# 📸 Photogram

A modern full-stack Instagram-inspired social media platform built with React, Node.js, PostgreSQL, Socket.IO, and Cloudinary.

---

## 🚀 Live Demo

Frontend:https://photogram-eta.vercel.app
Backend: https://photogram-backend-plum.vercel.app

---

## ✨ Features

### 👤 Authentication
- Register/Login
- JWT Authentication
- Secure Password Hashing
- Protected Routes

### 📷 Posts
- Create Posts
- Upload Images/Videos
- Like & Comment
- Delete Posts
- Feed System

### 🎬 Reels
- Vertical Reel Feed
- Video Uploads
- Auto Play Videos
- Infinite Scroll

### 📖 Stories
- Upload Stories
- 24-hour Expiry
- Story Viewer
- Story Reactions

### 💬 Messaging
- Real-time Chat
- Socket.IO Integration
- Message Notifications
- Responsive Mobile UI

### 🔔 Notifications
- Like Notifications
- Follow Notifications
- Real-time Updates

### 👥 Social Features
- Follow / Unfollow
- User Profiles
- Suggested Users
- Search Users

### 📱 Responsive Design
- Mobile Friendly
- Tablet Support
- Desktop Optimized
